# 수출·수주 주간 뉴스레터 (EXPORT LETTER)

재정경제부 수출플러스지원단의 **주간 수출·수주 뉴스 스크랩**을 대신해 주는 웹 앱이에요.
매주 월요일, 버튼 한 번으로 4개 경제지(매일경제·한국경제·서울경제·아시아경제)의 지난 한 주 기사 중
수출·수주 소식 10건을 골라 **쉬운 말 해설이 붙은 뉴스레터 화면**과 **텔레그램에 붙여넣을 공유용 글**을 만들어 줘요.

> 이 저장소는 학습·시연용으로 공개한 것이에요. 기사 전문은 저장하지 않고, 제목·원문 링크·짧은 요약만 사용해요.

## 무엇을 해 주나요

| 기능 | 설명 |
| --- | --- |
| 기사 선별 | 네이버 뉴스 검색 API로 4개 경제지 기사를 모으고, 수출·수주 기사만 걸러 중복(같은 사건)을 줄여 10건을 골라요 |
| 기간 자동 계산 | 공유일은 항상 월요일 오전 9시, 기사는 직전 화요일 0시부터(한국 시간) |
| 쉬운 말 해설 | 기사마다 이모지·쉬운 제목·"뭐라고?"·"왜 중요해?"·한 줄 요약(AI, 기사에 없는 숫자는 검사로 걸러내요) |
| 공유용 글 | `번호. 제목 (YY.M.D. 매체)` + 링크 형식, 복사 버튼 |
| 지원 안내 | 기사와 관련된 수출 플러스 지원 제도, 협력기관, 바로가기 |
| 권역별 보기 | 기사 속 지역 이름으로 7개 권역(수도권·충청권·호남권·대경권·동남권·강원권·제주권)에 묶어 보기 |
| 카드 넘기기 | `/cards` 에서 기사를 핸드폰처럼 한 장씩 넘겨 보기 |

## 사용 흐름

앱 접속 → **이번 주 기사 선별** 버튼(20초쯤 걸려요) → 기사 확인 → **공유 · 유관 기관** 탭에서 공유용 글 복사 → 텔레그램에 붙여넣기

AI 해설은 실수할 수 있어요. 공유 전에 원문과 맞는지 한 번 확인해 주세요.

## 기술 스택

- Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4
- 뉴스 수집: NAVER API HUB 뉴스 검색
- 해설 생성: OpenAI (`gpt-4o-mini`), 서버 코드에서만 호출
- 배포: Vercel (서울 지역)

## 로컬에서 실행하기

1. 저장소를 내려받고 패키지를 설치해요.

   ```bash
   git clone <이 저장소 주소>
   cd my-app
   npm install
   ```

2. 프로젝트 폴더에 `.env` 파일을 만들고 아래 값을 직접 채워요. (`.env`는 `.gitignore`에 등록되어 있어 저장소에 올라가지 않아요)

   ```
   OPENAI_API_KEY=
   NAVER_CLIENT_ID=
   NAVER_CLIENT_SECRET=
   ```

3. 개발 서버를 켜요.

   ```bash
   npm run dev
   ```

   브라우저에서 http://localhost:3000 을 열어요.

## 확인 명령어

```bash
npx tsc --noEmit      # 타입 검사
npm run lint          # 코드 검사
npm run build         # 빌드 확인
node scripts/check-filter.mjs   # scripts/ 안의 검사 스크립트(기간·필터·중복·공유글 등)
```

## 보안 안내

- API 키는 서버 코드에서만 쓰고 브라우저로 내려보내지 않아요.
- 기사 페이지는 허용한 4개 매체의 https 주소만 서버가 읽어요.
- 기사 생성 API는 같은 사이트 화면에서 온 요청만 받고 호출 횟수에 상한이 있어요.
- 배포 주소는 Vercel 접근 보호(Vercel Authentication)로 잠겨 있어서, 권한을 준 사람만 열 수 있어요.
- Vercel 함수는 서울(`icn1`) 지역에서 실행돼요(`vercel.json`).
- 실제 기관에서 쓸 때는 OpenAI·네이버 API 사용량 한도 설정이 함께 필요해요.

## 폴더 구조

- `app/` 화면과 API (`/api/newsletter`, `/api/images`)
- `lib/` 기간 계산, 기사 수집·필터·중복 제거·순위, 공유 글, AI 해설, 지원 안내 등 핵심 로직
- `scripts/` 로직 검사 스크립트
- `PRD.md` `PLAN.md` `DESIGN.md` 기획·계획·설계 문서
